# Incident Library: reports and corrections

[![Incident Library MCP connector – tool definition quality and endpoint health on Glama](https://glama.ai/mcp/connectors/com.benchlet/incidentlib/badges/score.svg)](https://glama.ai/mcp/connectors/com.benchlet/incidentlib)

This repository takes two kinds of issues for [Incident Library](https://benchlet.com/incidentlib/app), the searchable collection of public post-incident reports.

- **Propose a case.** A public post-incident report (a postmortem page, an engineering blog post, a status page incident, a talk or a runbook entry) that the library should write up. Use the *Case proposal* issue form.
- **Report a mistake.** A fact in a case that does not match its source, a broken link, or a wrong category. Use the *Correction* issue form.

The library's code and data are not in this repository. Cases are written up by hand from the report you point at, in English and Korean, and published with a link to the original. Every issue gets an answer here when the case is published or the correction is made.

The case texts, the category list and the API answers are available under CC BY 4.0; the original reports keep their own licences.

# Incident Library: 제보와 정정

[Incident Library](https://benchlet.com/incidentlib/app/ko) 에 보내는 이슈 두 종류를 받는 저장소입니다. Incident Library 는 공개된 장애 보고서를 사례 하나하나로 구조화해 증상으로 찾는 검색 서비스입니다.

- **사례 제안.** 라이브러리에 넣을 만한 공개 장애 보고서(포스트모템 페이지, 기술 블로그 글, 상태 페이지의 사고 기록, 발표, 런북 항목)를 알려 주세요. *Case proposal* 이슈 양식을 씁니다.
- **오류 신고.** 사례의 내용이 출처와 다르거나, 링크가 깨졌거나, 분류가 틀렸을 때 알려 주세요. *Correction* 이슈 양식을 씁니다.

서비스의 코드와 데이터는 이 저장소에 없습니다. 사례는 알려 주신 보고서를 읽고 사람이 영어와 한국어로 써서 원문 링크와 함께 공개합니다. 사례가 공개되거나 정정이 반영되면 이슈에 답을 남깁니다.

사례 글, 분류 목록, API 응답은 CC BY 4.0 이고, 원문 보고서는 각자의 라이선스를 따릅니다.
